# 008 overseas-sales — 海外売上高検索

金融庁 **EDINET** の有価証券報告書 (有報) から「**海外（地域別）売上高 /
海外売上高比率**」を構造化し、最大 5 年の推移を可視化するサービス。
005 yuho-quant（受注高/受注残高）の姉妹版。

> kabulab mono-repo (`services/overseas-sales/`) として配置され、
> `https://kabulab-cf.satoki252595.workers.dev/overseas-sales/*` で公開される。

## コンセプト

- 有報の **地域別売上開示は非構造化** (会社ごとに表の作りが違う)。これを
  実データ精査 → 決定論的パーサで構造化 → D1 化して横断検索・スクリーニング。
- 取得範囲は「海外売上 + 書類メタのみ」。全 XBRL ファクトは取り込まない。
- 一次データ（有報 ZIP）は 005 が docId キーで Notion へ実体アーカイブ済み
  （ルール6）。008 は重複アップロードせず派生構造化のみを持つ。

## 海外売上高の開示パターン（実地調査の結果）

`tmp/probe-overseas.ts` で 6 月提出の実有報を精査し、開示は概ね 3 系統に
集約されると確認した。

### GEO_ROWS — 地域=行（新収益認識基準の地域別収益分解：現行の主流）

「主たる地域市場」「地域ごとの情報」「地域別」の見出しの下に、行ラベルが
地域（日本/本邦・アジア・北米・欧州・中国・その他…）の表。値列は
**合計列**（報告セグメント×地域マトリクスの「合計/連結財務諸表計上額」）/
**当期列**（前期・当期 2 年表）/ **単一数値列** のいずれか。総額は
「外部顧客への売上高/顧客との契約から生じる収益/合計」行。
製品ブロック + 地域ブロックが同じ列見出しを共有して縦積みになる表もある
（地域ブロックだけ拾う）。

### GEO_COLS — 地域=列

ヘッダに地域（日本/本邦 + 海外地域）が並び、「外部顧客への売上高」行が
地域別の値、「連結/合計」列が総額。横並び 1 行の地域別売上や、報告セグメントが
地理区分（日本/タイ/中国・韓国）のセグメント情報表も含む。

### OVERSEAS_NOTE — 旧基準「海外売上高」注記

海外地域別に [海外売上高(金額), 連結売上高に占める割合(%)] を開示し、
合計（海外売上高合計）+ 連結売上高 を持つ。日本行は無い（海外のみ）。
新収益認識基準への移行で減少傾向だが、なお使う会社がある。

## 採用する数字

- **海外売上高** = 開示された海外地域行の合計（`total − 国内` ではない。
  「その他の収益」など地域按分されない分を海外に混ぜない）。
- **連結売上高** = 開示総額（外部顧客への売上高 / 連結）= 比率の分母。
- **海外売上高比率** = 海外売上高 ÷ 連結売上高。
- 「地域行の合計 ≈ 開示総額（1% 許容）」で誤読を検証し、外れたら却下する。
- 同一有報の複数表は **当期・連結・地域注記** に最も近い候補を採点で選ぶ。

## UI

- **検索 / 個別銘柄**: 海外売上高（億円）の積み上げ棒 + 海外売上高比率の折れ線
  （右軸）。最大 5 年。地域別内訳テーブル。欠損年は「未開示」と明示。
- **スクリーニング**: 海外売上高比率レンジ / 海外売上高 年率(CAGR) 下限 /
  **国・地域別エクスポージャ**（中国・中華圏 / 米国・米州 / 欧州 / アジアの
  対連結比率レンジ）/ 業種 + ファンダ条件（営業利益率・時価総額・PER・ROE・
  配当利回り）。直近比率の高い順。最低年数未満・直近比率算出不能は除外（架空値を
  作らない）。地域別は同義地域語を `REGION_BUCKETS` で束ね、その地域を**明示開示
  する会社だけ**を対象に、アジア等へ丸めている会社・複合地域行は中立で除外する
  （ルール1/2: 架空の比較可能性を作らない）。

## ルール遵守の要点

- ルール1/2: 構造化できない表は数値を作らず `parse_status` に事実を記録。
  金額欠損は NULL（0 で埋めない）。比率は分子・分母が揃う時だけ算出。
- ルール7: 海外売上高比率・年率・営業利益率・PER・ROE 等にバルーンヘルプ。
- 用語ヘルプは `src/shared/term-tip.ts` の正準実装を使用。
