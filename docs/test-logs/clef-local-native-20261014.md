# Clef native local scorer — 2026-10-14

`Cloudflare/clef-flash` revision `8b2e5fd17c09fd49bc2880b805d5323ec7ff4ff3` is a separate model from the former SemIf/Qwen runtime. Its merged backbone and trained joint schema head are loaded together through the [official native loader](https://huggingface.co/Cloudflare/clef-flash/blob/8b2e5fd17c09fd49bc2880b805d5323ec7ff4ff3/joint_schema_model.py). Ordinary Qwen next-token probabilities are not substituted. The accepted native source SHA256 is `0e304cf7c6500e8bb59bef7e2afd2c6373f82596dfb3b57d1aa93c175e2dc3a3`.

`services/yuho-quant/scripts/clef_server.py` accepts the existing JSONL `{id,state,questions:[{qid,question,options:[trueDescription,falseDescription]}]}` transport. Each field is encoded as native `noul` with both criteria explicitly bound. It returns only `{id,answers:{qid:pTrue}}`; malformed input, duplicate identifiers, missing/extra outputs, invalid logits and nonfinite probabilities fail the whole request. Input text and native stdout/stderr are not forwarded to logs or responses.

The official encoder silently slices the state when `max_length` is reached. This server instead calls it with `max_length=sys.maxsize`, without `max_state_tokens`, then checks the complete encoded length against the explicit maximum (at most 16,000) before collation or forward. Overlong records are rejected, never shortened. Full local model members, all index-referenced backbone shards, native source, and installed Torch/Transformers/Safetensors versions must match `src/shared/clef/manifest.json` before loading. The loader is offline and MPS/BF16 only; automatic CPU fallback, quantization and alternate models are forbidden.
