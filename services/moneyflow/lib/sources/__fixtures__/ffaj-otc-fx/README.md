# FFAJ 店頭FX月次速報のフィクスチャ

取得元: `https://www.ffaj.or.jp/library/performance/fx_flash/`
取得日: 2026-09-27（ブラウザ相当 UA、直接 GET で HTTP 200。ログイン・CAPTCHA・
bot対策は確認されなかった）。掲載データは 2026年8月分（更新日 2026-09-14）。

## `index-page.sample.html`

**実ページ (2026-09-27 取得) からパーサが読む箇所だけを抜粋したもの。**
抜粋部分の文字列・タグ構造は改変していない。ナビゲーション・footer・
script/style を除いただけで、`更新日` 表示・対象月見出し・ファイルリンク表・
「過去の概況」リンクはそのまま。ページ全体ではなく構造検証に必要な範囲の
抜粋に留めている（このページ自体は FFAJ の一般公開ページであり、記載の
数値も月次で更新・上書きされる速報値）。

## xls 3 ファイル (`trading_vol_and_position.xls` / `open_position_with_mc.xls` /
`deposit_amount_information.xls`) は**コミットしない**

2026-09-27 に実ファイルを取得・検証はしたが（後述の検証済みの値を参照）、
リポジトリには実バイト列を置いていない。理由:

1. **このリポジトリは PUBLIC**（`gh repo view` で確認）。`pipeline/tests/fixtures/`
   の JPX・日証金 (JSF) フィクスチャは、取得当初トリム済みの実ファイルを
   コミットしていたが、「personal-only ライセンスの実データを公開リポジトリへ
   コミットすること自体が、ライセンスが禁じる『二次利用・再配信』にあたる」
   という理由で 2026-09-12 に**履歴ごと除去**された経緯がある
   (`pipeline/tests/fixtures/jpx/README.md` 参照)。本モジュールもこの
   既存ルールに合わせた。
2. FFAJ サイトの著作権表示 (`/exception/matters/`, 2026-09-27 確認) は
   「原則として協会が著作権を有する。ご利用にあたっては著作権法を遵守する
   こと」という一般的な文言のみで、JPX 統計のように「商用目的によるデータ
   収集・二次利用・再配信を許諾なく禁止する」という明文の禁止条項は確認
   できなかった。とはいえ商用可否は明記されておらず (`commercial_use: unknown`)、
   xls ファイルの表構造・体裁 (FFAJ が編集した表領域) を丸ごと再配布する
   リスクを避けた。

その代わりに `ffaj-otc-fx.test.ts` は、**このライブラリ (`xlsx` パッケージ、
`src/shared/jpx/sectors.ts` などが使うのと同じもの) 自身で** 実ファイルと
同一のシート名・ヘッダー行・列レイアウトを再現した xlsx バイト列を
テスト実行時にその場で組み立て、そこに**下記の実測値**（数値そのものは
事実であり創作性がないため著作物には当たらない）を埋め込んで検証する。
テスト対象のパーサ関数 (`XLSX.read` → セル読取) は実ファイルに対しても
2026-09-27 に手元で実行し、同じ値が取れることを確認済み（下表）。

## 実ファイルで見つかった実データの癖: 正味増減額の `"na"`

`deposit_amount_information.xls` シート `DATA` を実ファイル (2026-09-27
取得, 137ヶ月分) に対して手元で通しパースしたところ、系列先頭の行
(2015年4月) だけ「正味増減額」列が数値ではなく文字列 `"na"` だった
(前月データが無く `=③-前月③-①+②` が計算できないため)。それ以外の
136ヶ月・他の全列は例外なく数値。パーサはこの1件を型崩れではなく
「計算不能」として `null` を返すよう実装し (`na` 以外の非数値は従来どおり
throw)、`ffaj-otc-fx.test.ts` に合成データでの回帰テストがある。
