# next-stock-report — 次来る銘柄レポートの作成

毎月 **第1日曜・第3日曜** に配信する有料レポート「次来る銘柄」を、全上場銘柄
(約3,700社) から **過去に紹介していない1銘柄** を選んで書く。定期起動は
claude.ai のクラウド定期実行（金曜 19:52 JST、毎週起動して日付ゲートで2週に1回へ絞る）。
Macの定期実行は使わない。リポジトリの `CLAUDE.md`（ルール1・2: 架空値・
フォールバック禁止）に従う。

## 0. 前提（接続先）

| 用途 | 接続 | ID |
|---|---|---|
| 配信DB「メンバー向けコンテンツ」 | Notion MCP | data source `collection://bc6e6448-b324-45c9-b648-05819e265eb1` |
| 株価・指標・財務・開示一覧 | Cloudflare MCP `d1_database_query` | D1 `kabulab-cf` = `639c0315-0d41-4345-95ab-aec5906224ed` |
| 一次資料の索引（開示書類・原本） | Notion「株式情報」 | ④開示書類 `collection://920f9cce-7f2f-47cc-8791-bc7356631f40` / ③財務サマリ `collection://af5fd81a-96f5-4f0d-af56-da08cba0cd79` |
| 定性情報（シェア・市場規模・信用残・報道） | WebSearch | — |

- クラウド環境では WebFetch / curl による TDnet・株探などの直接取得がネットワーク
  ポリシーで拒否される（2026-10-18 確認）。本文の取得は WebSearch の要約と D1/Notion
  の保存データで行い、取れない値は「未確認」と書く。推測で埋めない。
- D1 `jss_supply_latest`（日証金）と Notion ⑧需給 は **personal-only**。選定の参考に
  使ってよいが、**レポート本文へ数値を転記しない**。信用残は Yahoo!ファイナンス等の
  公開値を WebSearch で取り、基準日を併記する。

## 1. 日付ゲート（定期実行時のみ）

```bash
TZ=Asia/Tokyo date '+%F %a'                  # 今日 (JST)
TZ=Asia/Tokyo date -d '+2 days' '+%F %d %a'  # 配信日 = 2日後の日曜
```

- 今日が金曜でない、または2日後の日曜の「日」が **1〜7（第1日曜）でも 15〜21（第3日曜）
  でもない** 場合は、何もせず「対象週ではないため終了」とだけ報告して終了する。
- 手動実行で配信日を指定された場合はその日付を使う。

## 2. 重複・冪等チェック

Notion SQL で `tags` に `次来る銘柄` を含む全行を取得する。

```sql
SELECT name, "date:publishDate:start" AS d, publishSettings
FROM "collection://bc6e6448-b324-45c9-b648-05819e265eb1"
WHERE tags LIKE '%次来る銘柄%' ORDER BY d
```

- 配信日と同じ `publishDate` の `次来る銘柄` 行が既にあれば **新規作成しない**（二重作成防止）。
  その行のURLを報告して終了する。
- `name` は `<コード>_<銘柄名>`。先頭のコード（`156A` のような英字入り4桁を含む）を
  全件抜き出し、**除外リスト** にする（公開・未公開・未来日付の予約分すべて）。

## 3. 一次スクリーニング（決定的・SQL）

1. 鮮度確認: `SELECT max(latest_date) FROM swing_stock_indicators` が配信日の
   7日前より古ければ、データ更新の遅延として **作成を中止** し理由を報告する（古い値で書かない）。
2. [`scripts/next-stock-report/screen.sql`](../../../scripts/next-stock-report/screen.sql) の
   `/*EXCLUDE*/` を除外リスト（`'3989','156A',...`）に置換し、D1 で実行する
   （SQLコメント行は除いて渡す）。条件の要旨:
   - 本決算3期連続の増収（3期で+20%以上）、営業利益率が2期連続で上昇し直近8%以上、
     会社予想も増収・営業増益（予想が無い銘柄は除外しない）
   - 終値 > 75日線、25日線 > 75日線、75日線からの乖離 +30%以内、RSI(14) 40〜75
   - 20日平均売買代金 3,000万円以上、時価総額 50億〜5,000億円
3. 0件なら条件を緩めず「該当なし」と報告して終了する（基準を黙って下げない）。

## 4. 二次選定（定性・上位10銘柄まで）

一次結果から、利益率の改善幅とテーマ性を見て最大10銘柄を深掘りし、下の採点表で
1銘柄に絞る。各銘柄で確認するもの:

- D1: 直近の四半期（`jss_financials` の 1Q/中間/3Q）の前年同期比、会社予想、
  `ir_disclosures` の直近90日の開示（上方修正・中期計画・市場変更・自社株買い・
  株式分割）、`swing_daily_ohlcv` の直近6か月の値動き
- Notion ④開示書類: 決算短信・説明資料・有報の開示日と原本の所在
- WebSearch: 世界/国内シェア、対象市場の成長見通し（出典付き）、新規事業、
  直近の信用買残・売残・信用倍率（公開値と基準日）、株価急変の理由

| 観点 | 重み | 見るもの |
|---|---|---|
| 需給（できれば良好） | 20 | 信用買残 ÷ 20日平均出来高（2日以下が望ましい）、買残の増減、信用倍率、出来高の伴った上昇か |
| テクニカル | 20 | 5日>25日>75日の並び、25日線付近の押し目か、RSIの過熱、直近高値との距離 |
| ミクロの成長 | 25 | 売上の伸び、営業利益率の連続上昇、直近四半期と会社予想、上方修正 |
| 長期の市場成長 or 高シェアのニッチ | 25 | 市場の成長見通し、世界/国内シェア、参入障壁 |
| 成長市場への新規事業 | 10 | 新製品・新事業・M&A・中計の具体性 |

- 赤字、監理/整理銘柄、上場1年未満で業績3期が揃わない銘柄、TOB・MBO公表済みは除く。
- 次点2銘柄と、選ばなかった理由を最終報告に残す（次回以降の候補にもなる）。

## 5. レポート執筆（既存の体裁に合わせる）

直近の掲載例（`372A_レント`、`446A_ノースサンド`）を `notion-fetch` で読んでから書く。
見出しはテンプレート「1111_銘柄名」と同じ順序・表記:

1. `# 投資戦略` — `<callout icon="💡">` の中に、太字の要約1段落（何の会社か・利益率の推移・
   直近の株価とPER等）＋箇条書き3〜4点（追い風、テクニカルと買い場/撤退ライン、需給、
   今後の見どころ）。
2. `# 銘柄紹介` — 事業内容を中学生でも分かる言葉で。専門用語はその場で括弧書きで説明。
   シェア・市場規模は出典の時点（例「2023年の会社資料で約50%」）を明記。
3. `# テクニカル分析` — 直近終値と日付、期間高値/安値、移動平均（5/25/75日）、RSI、
   MACD、直近20日の値幅と押し目水準、1日の値動き（ATR）、信用残（公開値・基準日付き）。
4. `# ファンダメンタルズ分析` — 要点の箇条書き → `＜PL分析＞` → 業績表
   （決算期／売上高／営業利益／営業利益率／1株配当、直近3期＋今期予想）→
   `＜同業他社分析＞` 表（予想PER／PBR／予想利回り／時価総額、同じ基準日の D1 値）。
5. `# カタリスト（主な材料）` — 次の決算、上方修正余地、市場変更、中計、新製品など。日付が
   未確定なら「未定」「要確認」と書く。
6. `# リスク` — 3〜5点。最後に一言まとめ（例「ぐらいですかね。」の口調は可）。
7. 末尾に `---` と斜体の「データ出所：…」1行（D1の基準日、EDINET、会社開示の日付、報道機関名）。

文体: 既存レポートと同じ「です・ます」＋ややくだけた語り口（「〜ですね」「〜かなと思います」）。
`<br>` で行内改行、区切りは `---`。数値は全角単位なしの半角数字＋「億円」「%」「倍」。

禁止事項（ルール1・2）:
- 出典のない数値、推測したシェア・市場規模、未確認の日付を書かない。分からない値は
  「未確認」と明記する。
- 分割前後で比較できない1株値は「（株式分割前）」等の注記を付け、勝手に換算しない。
- D1 に値が無い同業他社は表から外すか「データなし」と書き、別の値で埋めない。
- チャート画像は自動生成しない（運営者が配信前に貼る）。

## 6. Notion への作成

`notion-create-pages`（parent `data_source_id: bc6e6448-b324-45c9-b648-05819e265eb1`）

| プロパティ | 値 |
|---|---|
| `name` | `<コード>_<銘柄名>`（例 `6524_湖北工業`） |
| `tags` | `["次来る銘柄"]` |
| `publishSettings` | `未公開`（公開は運営者が確認後に手動で切替） |
| `date:publishDate:start` | 配信日（第1/第3日曜） / `date:publishDate:is_datetime` = 0 |
| icon | 💹 |

作成後に `notion-fetch` で読み戻し、6見出しが全てあること・表が崩れていないこと・
本文の主要数値（終値、PER、売上/営業利益、利益率）が D1 の値と一致することを確認する。
不一致があれば `notion-update-page` で直す。

## 7. 最終報告

- 作成したページのURL、配信日、選定銘柄と選定理由（採点表の点数）
- 次点2銘柄と見送り理由
- 「未確認」と書いた項目、取得できなかった情報源（拒否されたホスト名など）
- 公開前に運営者が行うこと: チャート画像の貼付、内容確認、`publishSettings` を `公開` へ
